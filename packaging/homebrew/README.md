# Homebrew-Tap für wetter

Deutschsprachiges Wetter im Terminal, mit interaktivem Dashboard und JSON-Ausgabe.

```bash
brew install Witzelfitz/tap/wetter
wetter --tui Zürich
```

Aktualisieren:

```bash
brew update
brew upgrade Witzelfitz/tap/wetter
```

[Quellcode und Dokumentation](https://github.com/Witzelfitz/wetter) · [Releases](https://github.com/Witzelfitz/wetter/releases)

Die Formel installiert die fertigen Release-Binaries. Unterstützt werden macOS 14+ (Apple Silicon und Intel) sowie Linux x86-64 mit einem Ubuntu-22.04-kompatiblen glibc-System. Wetterabfragen benötigen Internetzugang. Der kostenlose Open-Meteo-Endpunkt ist für nicht kommerzielle Nutzung vorgesehen.
